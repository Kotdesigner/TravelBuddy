# TravelBuddy website

This branch (`gh-pages`) holds only the promo website. The app itself lives on `main`.

The promo page for [TravelBuddy](https://github.com/Kotdesigner/TravelBuddy), the free road trip app for Western Australia.

Live: https://kotdesigner.github.io/TravelBuddy/ · The app: https://travelbuddy-v1-wa.netlify.app
